# mobile/shell — 连接界面（本地 / 远程）

`mobile-connect-0.2` 新增。手机端启动后打开的不再直接是游戏客户端，而是这一页：它把原来的「开始」按钮拆成
「本地」与「远程」，让玩家选择**用这台手机自己跑服务器**，还是**加入别人已经开好的主机**（局域网、公网、内网
穿透都算）。

```
浏览器 / WebView ──▶ http://127.0.0.1:<port>/connect/     ← 只有本机（localhost）看得到
                     http://<手机IP>:<port>/              ← 别人打开仍是原来的默认界面
                     http://<手机IP>:<port>/connect/      ← 交给他人的地址若手动加 /connect/ 也会回到默认界面
```

## 为什么是一个独立页面

游戏客户端是 `/js/main.js` 带一整套模块图，而「选本地还是远程」要在**服务器可能根本用不上**的时候就能显示与
操作。所以这一页刻意不依赖客户端：它只用 `theme.css` / `components.css` / `screens/title.css` 里的设计变量与
类名（按钮、输入框、括号边框、点阵徽记、雷达与山脊背景），由服务器单独挂载在 `/connect/` 上，游戏本身的任何
路由都没有被改动 —— 非 localhost 的访问者拿到的仍是完全未修改的默认初始界面。

## 交互（按需求实现）

| 步骤 | 行为 |
|---|---|
| 初次进入 | 「开始」被均分为两个按钮：「本地」绿色主色调、「远程」白色主色调，均为描边样式 |
| 输入代号 | 等同于点「本地」，左侧按钮向右扩大到原按钮的 2/3，「远程」字样隐去，另一侧收缩 |
| 点「本地」 | 按钮变为实心绿色（与「开始」完全相同的填充、斜纹、发光的逻辑），再次点击进入游戏，逻辑与原「开始」一致 |
| 点「远程」 | 右侧按钮向左扩大到 2/3，「本地」字样隐去；「博士代号」以逐字拆散重组的方式变为「链接地址」，右侧英文
 `CALLSIGN` 隐去、原位置出现「局域网/公网链接」；输入框改为链接输入，左侧绿色人像变为绿色锁链图标；按钮变为实心白色 |
| 再次点「远程」 | 读取输入框内的链接：能连上 → 由 APK 的组件（新的 WebView）打开并渲染对方的游戏，同时**停止本机服务器**；连不上 → 弹出提示框「请输入有效链接」，并在提示里给出「用浏览器打开」的入口，以便看到防火墙 / 域名认证的拦截页面后自行判断 |
| 回退 | 远程游戏里按返回键 → 回到连接界面（本机服务器已停止，会有一行说明） |

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面骨架：复用游戏标题页的点阵徽记、雷达与山脊背景、四角标注、控制台外框与页脚 |
| `shell.css` | 只在游戏设计像素体系（`1rem = 100 设计像素 @1920×1080`）上追加：双按钮的分裂/生长/填充、链接输入态、提示框；并按 1500 / 1100 / 820 px 与低高度窗口做分辨率适配 |
| `shell.js` | 状态机：徽记点阵绘制、标签拆字重组、本地（动态 `import('/js/main.js')` + `enterSession`）、远程（校验 + 交给 App）、自绘提示框 |
| `util.js` | `isLoopbackHost()`、`normalizeLink()`、`probeLink()`、Android 桥接探测 |

## 与 App 的接口

`MainActivity` 通过 `addJavascriptInterface` 注册 `window.SP_BRIDGE`（**在执行页面脚本之前就存在**，因此不依赖
任何注入时机）：

```js
window.SP_BRIDGE = {
  isApp(),              // 是否运行在 APK 内
  mode(),               // 'local' 或 'remote'（App 是否是为了某个链接而被打开）
  initialUrl(),         // 该链接，或 ''
  openRemote(url),      // 新开一个 WebView 加载该链接，并在页面加载完成后停止本机服务器
  openExternal(url),    // 交给系统浏览器（用户验证被拦截的链接用）
  stopLocalServer(),    // 向本机 Node 进程发 SIGTERM
};
```

在普通浏览器里打开这一页时（例如同机的桌面浏览器），`SP_BRIDGE` 不存在，`openRemote` 退化为直接跳转。

页面里还有一个空的 `#app` 与 `#boot`：游戏客户端会渲染进 `#app`（`public/index.html` 里同样是这两个节点），
“本地”被选中后由它们接管整个页面。
